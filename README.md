# Ley 20.869 — Protegemos la lactancia materna

Página informativa sobre la **Ley 20.869**, que regula y sanciona la publicidad de sucedáneos
de la leche materna, y sobre cómo denunciar su incumplimiento en el Sistema OIRS del MINSAL.

**Elaboración:** Comité de Lactancia Materna, CESFAM Tongoy — Municipalidad de Coquimbo.

## Contenido

- `index.html` — página completa (HTML + CSS en un solo archivo, sin dependencias de build).
- `assets/qr-oirs-minsal.png` — código QR que apunta a `https://oirs.minsal.cl/`.
- `assets/ejemplo-oirs.png` — captura de ejemplo del formulario del Sistema OIRS.
- `assets/logo-coquimbo.png`, `assets/logo-cesfam-tongoy.png` — logotipos institucionales.

## Publicar en GitHub Pages

1. Crea un repositorio y sube estos archivos manteniendo la estructura de carpetas.
2. En el repositorio: **Settings → Pages**.
3. En *Source* elige **Deploy from a branch**, rama `main` y carpeta `/ (root)`.
4. Guarda. La página queda disponible en `https://<usuario>.github.io/<repositorio>/`.

## Notas técnicas

- Diseño responsivo (móvil, tablet y escritorio) con tipografías `Caveat` y `Quicksand`
  cargadas desde Google Fonts, con respaldo a tipografías del sistema.
- Contraste de texto ajustado respecto del material original para cumplir criterios de
  legibilidad (texto oscuro sobre tarjetas claras en lugar de blanco sobre lila).
- El QR fue regenerado para apuntar directamente a `https://oirs.minsal.cl/`.
